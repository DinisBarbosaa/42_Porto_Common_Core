## 📖 About 42

42 is a project-based, peer-reviewed programming school with no teachers, no classes, and no textbooks. Students learn by building real projects from scratch, defending their code in peer evaluations, and progressing through a curriculum that starts with C fundamentals and builds toward systems programming, algorithms, and beyond.
